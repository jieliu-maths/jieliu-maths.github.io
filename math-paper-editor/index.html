01Choose the scope.

Review without writing, edit a selected section, inspect a proof more deeply, or authorize restructuring of an existing argument.

02Keep concerns explicit.

A grammar correction cannot silently repair a theorem. Missing assumptions, proof gaps, and unverified references are reported separately.

03Inspect the revision.

Local snapshots and guarded replacements record the edit. Differences outside recorded operations remain visibly unattributed.

Instructions and local tools

Where does Python fit?

The skill's core is a set of editing instructions. Python runs the bundled local tools for reliable records and upgrades; it is not the language in which an AI must think about mathematics.

Task Local requirement
Read the instructions or perform a read-only review An AI host able to load the skill; local Python is not needed for the instructions themselves.
Use the default tracked editing, installation, upgrade, or test tools Python 3.10+, using the standard library. Snapshots, hashes, guarded edits, and diffs run locally.
Use this web demonstration A browser with JavaScript; no Python installation.
Compile a LaTeX manuscript into a PDF An available TeX compiler or host compilation service. Python alone does not compile LaTeX.

The supplied v0.1.0 editing procedure uses the Python helper. If the required records cannot be created, the skill continues with read-only work and reports the limitation. Host/model data handling still follows the selected service's policies.

What has been checked?

The first release passed 38 deterministic tool tests and four macOS/Linux CI combinations. An initial assistant-assessed evaluation ran 10 synthetic cases with the skill and 10 with an unaided baseline. Both met the case criteria; no mathematical accuracy improvement was demonstrated. The reports, observed sources, and limits are public.
