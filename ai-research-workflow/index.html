Workflow 02 · Mathematical writing

Reviewing and revising mathematical manuscripts

Math Paper Editor supports scoped mathematical review and faithful LaTeX revision. It separates mathematical concerns from language edits and makes the actual source changes inspectable.

The current version supports read-only review, conservative editing, deeper proof inspection, and authorized restructuring of existing arguments. Its demonstration shows what “edit only the Introduction” allows, including a valid zero-change outcome.

Implementation notes and AI4S

The instructions and read-only review do not themselves need local Python. Bundled snapshots, guarded edits, validation, installation, and upgrades use Python 3.10+. The browser demonstrations use JavaScript; compiling a manuscript requires an available TeX compiler or host service.

An experimental AI4S profile extends the workflow conventions to data provenance, controls, frozen evaluation, and reproducibility. The main emphasis here remains mathematical work.
